## Prompt

1. **Primary Theme:** What's the main issue or request?
2. **Urgency:** Low / Medium / High / Critical
3. **Category:** Feature Request / Bug / UX Issue / Integration / Other
4. **Sentiment:** Positive / Neutral / Negative
5. **Action Recommended:** What should the PM do?
6. **Priority Score:** 1-10 based on impact and urgency
