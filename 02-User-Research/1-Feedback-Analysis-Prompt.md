# User Feedback Analysis Prompt

## Purpose
Automatically categorize and analyze customer feedback at scale

## Prompt Template
Analyze this customer feedback and provide:

1. **Primary Theme:** What's the main issue or request?
2. **Urgency:** Low / Medium / High / Critical
3. **Category:** Feature Request / Bug / UX Issue / Integration / Other
4. **Sentiment:** Positive / Neutral / Negative
5. **Action Recommended:** What should the PM do?
6. **Priority Score:** 1-10 based on impact and urgency

**Customer Feedback:** [PASTE FEEDBACK HERE]

---

## AI Analysis Capabilities Demonstrated

Examples showcase how AI feedback analysis will:

✅ **Automatically categorize** diverse feedback types (bugs, features, UX, commercial)  
✅ **Assess urgency** based on language cues, customer tier, and business impact  
✅ **Detect sentiment** from tone, word choice, and context  
✅ **Recommend actions** with specific next steps for PMs  
✅ **Calculate priority scores** combining urgency, impact, and customer value  
✅ **Extract metadata** like customer tier, churn risk, expansion opportunity  
✅ **Identify patterns** like competitive gaps, onboarding friction, performance issues  
✅ **Route appropriately** to product, engineering, sales, or support teams

**Time Savings:** Instead of manually reading and analyzing each piece of feedback (5-10 minutes each), PMs can review AI-generated summaries (30 seconds each) and focus only on high-priority items.
